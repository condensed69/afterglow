## What

Adds a **Branches** section to `AGENTS.md` making the branch-base rule explicit,
and documents the `pre-push` hook that now enforces it.

Docs only. No game code, no `VERSION`/`CHANGELOG`/`SAVE_VER` movement.

## Why

On 2026-08-12 a branch was cut while still standing on another feature branch
(PR #55). That parent was squash-merged, so the carried commits became
content-duplicates with different SHAs, the PR went `mergeable_state=dirty`, and
**GitHub created no check runs at all** — no gates, no review. The work looked
finished and nothing had verified it.

`AGENTS.md` already said "before opening a PR, rebase onto the latest `main`".
Prose alone did not hold. It is now backed by a `pre-push` hook in the hermes
container that refuses any push not rooted on the current `origin/main` and
prints the exact repair. This change is the prose half of that pairing — the
half that lands in the agent's context every session.

## Gates

All three run on this tree, all pass:

- `node --check game.js` — pass
- `node economy.test.mjs` — pass (all non-skipped tests)
- `node pacing.mjs` — pass (prestige scenario)
